# Illinois Road Test Prep

Animated, step-by-step practice for the Illinois (Chicago) in-car driving test: turns, traffic lights, stop and yield signs, roundabouts, school buses, railroad crossings, crosswalks, emergency vehicles, lane changes, yellow-line rules, U-turns, turnabout, backing, hill and parallel parking.

Open `index.html` in a browser, or visit the GitHub Pages site.

Study aid only. Always follow posted signs and your examiner's instructions.
